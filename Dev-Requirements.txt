Project Requirements: Travel Recommendation Web Application

1. CORE PAGES & NAVIGATION
- Home Page: Introduction to the platform and hero section.
- About Us Page: Company information and team membership guidance.
- Contact Us Page: Contact info and email inquiry form.
- Navigation Bar Elements: Home, About Us, Contact Us, Search Input, Search Button, Clear Button.

2. FUNCTIONALITY
- Search System: Implement keyword-based search for "beach", "temple", and "country".
- Data Source: Fetch travel data from travel_data.json.
- State Management: React hooks for managing search results, loading, and navigation.

3. DATASET
- Comprehensive data for Australia, Japan, Brazil, various Temples, and world-class Beaches.

4. TESTING SUITES (Verified 100+ tests total)
- 15x Selenium, 15x Playwright, 15x Cypress, 15x Cucumber.
- 8x Load, 8x Stress, 8x Performance, 8x Unit, 8x System, 8x Integration, 8x Security, 8x End-to-End.

FILE DESCRIPTIONS & TECHNOLOGIES:

- /index.html: The HTML5 entry point. Configures viewport and loads the React application script.
- /package.json: Project manifest. Manages dependencies (React, Tailwind, Lucide, Motion) and scripts.
- /vite.config.js: Vite Build Tool configuration. Handles React plugin integration and path aliasing.
- /src/App.jsx: React (JavaScript) - The core application component. Handles routing logic, search algorithms, data fetching, and UI rendering.
- /src/main.jsx: React/DOM - Bootstraps the React application into the root DOM element.
- /src/index.css: Tailwind CSS - Entry point for utility-first styling and theme configuration.
- /public/travel_data.json: JSON - Static database containing structured information about travel destinations.
- /.env.example: Environment blueprint for securing sensitive API keys.
- /Dev-Requirements.txt: Documentation - This file outlining project scope and technical stack.
- /README.md: Markdown - User-facing documentation and project overview.
- /TEST_FOLDERS/*.js: JavaScript - Testing suites for cross-browser, performance, and unit verification.
- /TEST_FOLDERS/*.txt: Text - Automated reports documenting test execution results and passes.

TECHNOLOGY STACK:
- Frontend: React 19 (Functional Components, Hooks).
- Styling: Tailwind CSS 4 (Utility-first framework).
- Icons: Lucide-React (Vector icons).
- Animations: Motion (formerly Framer Motion) for fluid UI transitions.
- Build Tool: Vite 6 (ESM-based fast build tool).
- Testing Tools: Selenium, Playwright, Cypress, Cucumber.
